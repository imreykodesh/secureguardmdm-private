# דיווחים והצעות — סוויצ'

זהו המאגר הציבורי לדיווחים, שאלות והצעות הנוגעים לאפליקציית סוויצ'. קוד המקור אינו מתפרסם במאגר זה.

## לפני פתיחת דיווח

- יש לתאר מה קרה, מה היה צפוי לקרות ואילו צעדים הובילו לכך.
- אפשר לציין את דגם המכשיר וגרסת Android, אך אין לפרסם מספר סידורי או מזהה ייחודי.
- אין לצרף סיסמאות, קודים, tokens, כתובות דוא"ל, פרטי תשלום או מידע אישי.
- יש להסיר מידע רגיש מצילומי מסך ומלוגים לפני צירופם.
